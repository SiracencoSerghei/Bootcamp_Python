# 🏥 Day 80: Analyzing Data Like Dr. Ignaz Semmelweis

## 📖 Your Story  
Сьогодні ви станете лікарем, а саме – доктором Ігнацом Земмельвайсом, угорським лікарем, який працював у Віденському загальному шпиталі в 1800-х роках.  

У той час люди не знали про бактерії, віруси та мікроби. Хвороби пояснювали "поганим повітрям" або злими духами. Однак у XIX столітті лікарі почали приділяти більше уваги анатомії, проводити розтини та використовувати дані для обґрунтування своїх висновків.  

Земмельвайс підозрював, що у Віденській лікарні щось не так із процедурами, адже жінки у пологових відділеннях масово помирали від післяпологової лихоманки (puerperal fever). Сьогодні ви проведете подібний аналіз даних.

## 🎯 Чого ви навчитеся:

- **Як створювати переконливі аргументи за допомогою даних.**
- **Як накладати гістограми** для порівняння різних розподілів.
- **Як використовувати Kernel Density Estimate (KDE)** для графічного відображення розподілу.
- **Як застосовувати `scipy` для перевірки статистичної значущості** через p-значення.
- **Як підсвічувати різні частини часових рядів** у Matplotlib.
- **Як додавати та налаштовувати легенду** в Matplotlib.
- **Як використовувати `numpy.where()`** для обробки даних за умовою.
