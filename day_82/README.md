# Morse Code Converter
## Description
This is a text-based Python program that converts strings into Morse code. It takes an input string, translates each character into its corresponding Morse code representation, and outputs the result.
## Features
- Converts letters (A-Z, a-z) and numbers (0-9) into Morse code.
- Supports common punctuation marks.
- Ignores unsupported characters.
- Outputs Morse code with spaces separating letters and slashes (/) separating words.
## Installation
Clone this repository: `git clone https://github.com/your-username/morse-code-converter.git` Navigate to the project folder: `cd morse-code-converter` Ensure you have Python installed (version 3.x recommended).
## Usage
Run the script using: `python morse_converter.py` ### Example input: `Hello, World!` ### Example output: `.... . .-.. .-.. --- / .-- --- .-. .-.. -..`
