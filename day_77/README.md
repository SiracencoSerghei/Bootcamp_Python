# День 77: Цілі

## Що ви досягнете до кінця дня

Жоден курс Data Science не може бути повним без вивчення NumPy (числовий Python).  
NumPy — це бібліотека Python, яка використовується майже в усіх галузях науки та техніки.  
Це практично **САМИЙ стандарт** для роботи з числовими даними в Python.  
Приклади використання NumPy говорять самі за себе 😮  

Поки що ми використовували Pandas, яка створена на основі NumPy.  
Подумайте про Pandas як про високорівневий інструмент обробки даних, який включає функції для:

- роботи з часовими рядами,  
- групування,  
- об’єднання,  
- пошуку відсутніх даних.  

З іншого боку, NumPy блищить із завданнями низького рівня, такими як **серйозні математичні обчислення**.
